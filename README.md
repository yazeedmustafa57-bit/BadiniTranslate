# Badini Translate 🇰🇼

Eine Übersetzungs-App für Kurdisch-Badini. Lädt die Website https://translator-site-five.vercel.app als native Android WebView-App.

## Features
- WebView mit voller Website-Unterstützung
- Dark/Light Mode von der Website
- Bild-Upload aus Galerie oder Kamera
- Datei-Upload
- Swipe-to-Refresh

## Build
```bash
./build-with-wrapper.sh
```
